# Project 4: Examination Result and Grace-Mark Validation

## Problem Description
This project processes student marks across multiple subjects, applies subject-wise passing criteria, and provides grace marks to students who score between 35 and 39. It calculates total marks and average marks and generates the final examination result and classification without exceeding the maximum marks.

## Programming Language
Python

## Concepts Used
- Variables and data types
- Lists
- For loops
- Conditional statements (if, elif, else)
- Arithmetic operators
- User input and output

## Files Included
- `Question_04_Examination_Result.py` – Python source code
- `Screenshots/` – Code and output screenshots

## How to Run
1. Download the Python file.
2. Open it using Python or VS Code.
3. Run the program.
4. Enter the student name and marks for three subjects.
5. View the final examination result.

## Conclusion
The program validates student marks, applies the specified grace-mark policy, calculates the average, and displays the final result and classification.
